# 审查与交付记录

## 内容与审美

- [ ] 参考身份、实际查看范围、观察与解释可追溯；本片规则对应具体表达，详见STYLE_BIBLE。
- [ ] 使用ART_REVIEW记录实际画面/时间段、影响与局部修正；不以AI自评分代替证据。
- [ ] 与简报的一句话表达一致；结尾回应前面的变化。
- [ ] 相邻镜头的角色、主物件、光线和视觉规则连续。
- [ ] 每镜头起中末、转场、峰值动作、文字进出均有覆盖。
- [ ] 实际打开并查看导出的 QA 图，记录文件与发现。
- [ ] 连续运动已检查，不只看孤立的漂亮截图。
- [ ] 目标设备的字幕、对比度、净空和裁切通过。

## 声音与技术

- [ ] 旁白、音乐、环境声与音效关系明确；卡点与停顿正确。
- [ ] 记录实际试听方式；无法试听时如实说明，不写“已亲耳试听”。
- [ ] 成片默认60fps恒定帧率；时长、分辨率、解码帧数、逐帧时间戳、编码和声轨与配置一致。
- [ ] 有声项目audio.required=true；缺失音轨不通过。
- [ ] 低帧率素材记录fps_conversion及实际处理证据；时间戳通过不证明原生画面。
- [ ] 区分源帧率、输出帧率和插帧；不把 60fps 容器称为原生 60fps。
- [ ] 成片完整解码通过，编码后关键帧复查通过。

## 交付

- [ ] 母版、轻量版、源项目、字幕/文案与资产清单。
- [ ] 本地校验和与版本记录。
- [ ] 使用已授权的交付渠道；上传后读取服务端大小与元数据。
- [ ] 保持私人分享范围；不自动发布公开链接。
- [ ] 远端大小相同仅称大小核对；做了下载回验/服务端校验和比对才称内容哈希一致。
- [ ] 提供实际可访问的链接，说明登录账号；失败时更换交付通道而不是反复压缩冒充修复。

机器通过项目、人工检查项目、尚未检查项目分别列明。
