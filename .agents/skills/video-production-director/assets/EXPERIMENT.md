# 一轮创作与发布实验

- ID、日期、账号阶段、关联知识条目/案例：
- 观众问题、一句话表达、预期收益路径：
- 本轮唯一主要假设：
- 基准与变化项；其它条件如何尽量保持：
- 主指标及完整口径；辅助指标；质量与成本限制：
- 观察窗口与数据来源；流量是否可分自然/付费：
- 没有历史基准时怎样建立首轮基准：
- 制作时间/费用上限与已有授权依据：
- 先验证文字/静帧/Animatic的何种失败：
- 预计作品数量、发布草案、是否已有发布授权：
- 何时继续、调整或停止（按自身基准设定，不写“平台必推阈值”）：
- 已知混杂因素：不同时段、选题差异、粉丝变化、投放、节日/热点：
- 实际结果、缺失数据、与预期相反的证据：
- 下轮只改什么；哪些资产可复用：
- 对知识条目的处理：保持候选 / 限定适用 / 降级 / 退休：

不同时间公开发布的作品属于观察性比较，不能声称是随机分流的 A/B 测试。先生成多个开场草稿进行低成本审看，不默认把近似重复视频反复发到账号。
