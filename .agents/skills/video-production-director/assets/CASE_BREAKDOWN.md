# 单案例拆解

## 身份、来源与可访问性

- 案例编号；账号、主页链接、平台、作品稳定链接/ID：
- 发布日期、抓取/观察日期、时长（无证据留未知）：
- 选入原因：同类/小体量/普通表现/明显高表现/商业内容：
- 来源与等级：metadata_only / reported / direct_review / first_party_test（可多选）：
- 完整视频是否实际看过、是否有声音；实际方法与缺失：
- 账号从零路径：已知起点、重要迭代、已有积累、不可知间隔：
- 数据：数值、单位、统计截止、公开/后台/媒体转述/估计；付费流量未知项：

## 逐段记录（只有观看证据才能填真实时间点）

| 起止秒 | 实际画面/动作 | 实际声音/文字 | 给观众的新信息 | 解释与不确定性 |
|---|---|---|---|---|
| | | | | |

没有完整视频时，此表留空。另写“根据报道的结构推测”，不伪装成观片记录。

## 内容、传播与收益

- 对观众的具体承诺、开场问题/动作：
- 信息/情绪如何推进；证据、转折和兑现在哪里：
- 为何可能收藏/分享/关注；标为假设而非后台事实：
- 系列预期；独有能力、资产或真实性来源：
- 商业行为有无直接证据；是否只有媒体报道；收入/利润分别是否可知：
- 同账号普通作品、早期作品、近似小账号比较：
- 样本缺口、相反证据、分发/受众/制作成本等混杂因素：
- 我们可迁移的一条机制；不具备的前提：
- 原创改写方案（不同对象、表达、镜头资产、声音）：
- 下一次低成本实验；失败标准；关联知识条目ID：
