# 案例预拆解 / 2026-10-24

## 先说明本轮做了什么

检索公开网页、阅读创作者访谈和官方资料，建立四个账号路径的预研究条目。没有访问其私有后台，没有验证真实净收益，没有把媒体转述当作我们测得的数据。抖音主站作品页未返回可观看内容，精选页提供了一部分元数据；没有绕过限制、下载他人视频或部署采集器。

以下“迁移假设”和“实验”都是我们的原创策划建议，不是报道原话，也不是已经被这些案例证明的因果规律。没有精确镜头时间表，因为本轮未完整观看这些原视频。它们不组成代表性样本，更不足以给出全体新作者成功率。

## C01 阿盐：《穿越山海经》——最接近神话叙事方向

**来源可确认的范围：** 新榜2026-07-06报道将该片描述为熟悉神话人物进入山海世界的冒险；2026-09-01访谈补充作者此前已有相关角色资产，并报道走红后获得品牌和媒体合作。以上是报道，不是后台或合同审计；不能据此计算利润或新手成功率。

来源：[作品报道](https://www.newrank.cn/article/detail/34596)、[后续访谈](https://newrank.cn/article/detail/34717)。后者明显围绕特定创作产品介绍，其工具效率和收益主张只作线索，不作为购买或收益预测依据；是否付费推广未独立核实。

**路径预拆解：** 已有兴趣和角色资产 → 新的故事组合 → 报道所述传播 → 报道所述合作。第一条作品、完整失败记录、成本、账号起始粉丝与投放情况未知。“从零”这部分不能补写。

**我们的迁移假设：** 观众可以先理解一个熟悉的问题/角色，再进入新的处境；视觉奇观有机会因故事目标而变得易懂。不能推断熟悉IP本身必然带来增长，也不照搬任何现代影视版的角色造型。

**原创实验：** 用一个原创旅人和一盏会记住声音的灯，讲一次“是否继续等待”的选择；先做30–45秒单场景草案。比较纯景物开场和人物遇到具体问题的开场，观察目标观众能否复述目标。先离线选稿，再考虑一条完整作品，避免上来复制20分钟规模。

**仍缺：** 实际原片、同账号普通作品、小体量同类对照、自有测试、商业交付成本。

## C02 AI疯人院 / 冯彬：《山海经》——与我们可控生产最相关

**来源可确认的范围：** 经济观察报2025-01-30采访记录了作者技术美术背景和长时间资产积累，介绍其查阅版本、手绘参考及后期修正的混合制作方式。它支持“不是只靠一句提示词”的个案判断，不证明人人都需要同样工序或投入。

来源：[经济观察报在澎湃的机构发布页](https://m.thepaper.cn/newsDetail_forward_30062322)。原站同文链接本次返回403，故保留可读发布页；报道中的当时模型能力不外推为2026年所有工具的限制。

**路径预拆解：** 专业与图像积累 → 早期AI视觉尝试 → 适应工具能力 → 成系列的古典世界呈现。起点已有技能与素材，不能称为“零经验八天起号”。

**我们的迁移假设：** 一份可复用的主体参考与人工修正环节，可能比每镜重新生成更利于一致性。这里迁移生产方法，不将作者的工时、产量或传播结果当我们的预算。

**原创实验：** 为一只原创杯子建立三视图、尺寸和材质表，先测三个镜头是否保持身份；未通过就调整资产/合成路线，而不是增加十个随机seed。

**仍缺：** 原片观片、完整普通作品对比、商业收入、当前账号身份链接与自己的可用镜头成本。

## C03 无穷小亮——用“看懂过程”补足纯视觉内容

**来源可确认的范围：** 新榜2020-08-30采访记录其原有微博积累、后来在抖音尝试并形成鉴定栏目，也记录了图书推广与品牌合作。中国农大2026-08-24刊载的作者文章强调展示推理过程。两个时期的材料支持栏目路径线索，不证明当前收入或某条视频后台表现。

来源：[早期采访](https://newrank.cn/article/detail/15267)、[作者署名文章的学校转载](https://news.cau.edu.cn/rwgs/b8197a1d09594390b4de714a6e471355.htm)。相关数字若引用，必须附当时口径；本包不把报道中的销量当作实收或利润。

**路径预拆解：** 已有专业与公众形象 → 新平台内容尝试 → 问题驱动的系列 → 与内容相关的商业表达。它不是全无积累的冷启动样本。

**我们的迁移假设：** 让观众看到一次变化的依据，可能比结尾只给一句哲理更有观看价值。专业资格不能靠美术效果替代。

**原创实验：** 用杯中热水/蒸汽讲一个有可靠依据的小问题，先验证解释能否被理解；知识不充分时改做明确的诗意虚构，不包装成科普。商业物品只在真实用途成立时引入。

**仍缺：** 同主题普通表现作品、原视频结构记录，以及从我们内容到需求的转化证据。

## C04 彭传明——器物内容的吸引力与真实成本

**来源可确认的范围：** 新榜作者在数英2021-11-09的报道记录其从短小手作内容到工艺系列的演进；人民日报海外版2024-12-02报道介绍其工艺制作所需的真实时间。它们提醒我们把实际劳动和制作成本算进模式，不能仅照抄画风。

来源：[早期路径报道](https://www.digitaling.com/articles/628102.html)、[人民日报海外版报道](https://paper.people.com.cn/rmrbhwb/pc/content/202412/02/content_30032345.html)。早期报道对商业状态的描述只属于当时，不能说作者现在没有商业收入。

**路径预拆解：** 已有手艺 → 早期短片 → 更清楚的步骤与系列 → 报道所述传播。团队规模、完整成本和现阶段商业数据未核实。

**我们的迁移假设：** 主体发生看得见的变化，能为安静节奏提供持续信息。我们可以借鉴“变化与使用”的叙事，不把AI合成冒充亲手完成的工艺纪录。

**原创实验：** “杯子的一个夜晚”以形态、盛水、蒸汽、使用痕迹推进。若是虚构视觉片，明确其创作属性；若解释真实工艺，先核对工序。

**仍缺：** 原片与普通片比较、目标用户反馈、受众是否匹配可能的服务客户。
