# 审美参考与反馈库

这里保存可追溯的参考卡和有范围的用户反馈，作为创作判断的依据。它不保证艺术质量或传播效果，也不把馆藏作品当作人人都应模仿的风格。

## 每次怎样取用

先读小索引 [INDEX.json](INDEX.json)，按本片问题选一个主要参考，必要时加一个补充参考。只读取相关卡和 [偏好记录](PREFERENCES.json) 中的相关条目；不自动加载全库、所有旧项目或整本SOP。若需要新的媒介、风格或运动参考，针对那个具体问题检索并核对，而不是把这三件作品混成固定配方。

参考分解为“来源事实、实际观察、我们的解释、本片原创规则、验证证据”。原图应按卡中的链接实际打开查看；本轮查看记录不能代替以后任务查看自己实际使用的素材。静态参考不证明运镜、剪辑或声音有效，动态部分须用本片预演验证。

## 维护与减负

个别项目的风格规则放该项目STYLE_BIBLE，不写成全局要求。最终反馈保留用户原话、对象与范围，再形成候选经验；合并重复条目、归档被替代条目。单次喜欢/不喜欢不能自动变成所有题材的规定。

主Skill只保留如何选择和评审的入口；详细方法在技能的art-direction.md，项目用STYLE_BIBLE和ART_REVIEW保存结果。审美判断、观看传播和商业收益分别验证。新增参考应解决一个明确问题，找不到用途的条目不为凑数量加入。
